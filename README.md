# Privacy-for-UNiFY

Privacy Policy — UNiFY Screener

Last updated: Feb 1, 2026

UNiFY Screener is a Chrome extension designed to enhance Screener.in by adding valuation tools, QoQ growth analysis, TradingView links, and chart downloads.

Your privacy is important to us.

Data Collection

UNiFY Screener does not collect, transmit, sell, or share any personal data.

The extension operates entirely on the client side.

Local Storage

The extension uses Chrome’s local storage API to save:

User-entered valuation assumptions (Bull/Base/Bear cases)

Analysis preferences

This data is stored only in your own browser and never sent to any external servers.

Website Access

The extension accesses https://www.screener.in/* only to read publicly available financial information displayed on the page. This data is used solely for calculations and UI enhancements.

No backend modification of Screener.in occurs.

Downloads

When you choose to export charts or visuals, files are downloaded locally to your device. Downloads occur only after explicit user action.

Remote Code

UNiFY Screener does not load or execute any remote code. All scripts and assets are bundled directly within the extension.

Third Parties

The extension does not use analytics services, trackers, or third-party APIs.

Changes

This policy may be updated in the future. Any changes will be reflected on this page.
